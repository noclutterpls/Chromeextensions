Privacy Policy for Clipboard Cleaner

Effective Date: May 22, 2026

Clipboard Cleaner is a browser extension designed to remove empty lines from clipboard text locally on the user's device.

Data Collection and Usage

Clipboard Cleaner does not collect, store, transmit, sell, or share personal data with third parties.

The extension processes clipboard text locally within the user's browser solely to provide its core functionality:

  • Reading clipboard text
  • Removing empty lines
  • Writing the cleaned text back to the clipboard

No clipboard content is transmitted to external servers.

Permissions Used

clipboardRead

Used to access clipboard text so the extension can detect and remove empty lines.

clipboardWrite

Used to write the cleaned clipboard text back to the clipboard.

storage

Used to save extension settings and preferences locally in the browser.

Remote Code

Clipboard Cleaner does not use remote code. All code required for the extension is packaged within the extension itself.

Third-Party Services

Clipboard Cleaner does not use analytics services, advertising services, tracking technologies, or external servers.
